## Normalization

1. `<style>`, `class`, `id`, per-path `fill`/`stroke` removed; a single `fill="#000"` on the root.
2. `viewBox` trimmed to the content box measured with `getBBox()` in Chrome; `width`/`height` attributes dropped.
3. `svgo@3.3.2` default preset, multipass, 2-decimal precision. Largest file is 9.0 KB (Sexto Abismo); all 16 are under 10 KB.
4. No `<text>`, no `<image>`, no raster in any file (checked by grep).

## Band CSS fix (site.css, "Client marks")

The mark box used `aspect-ratio: 3 / 1` with `display: inline-grid` and the image `max-height: 100%`. In an auto grid row that percentage resolves to none, so stacked marks (Vyv 102 px, Pax & Beneficia 94 px, Sexto Abismo 84 px) overflowed the 56 px row. The box is now `display: flex` with a fixed height (40 px phone, 56 px from 768 px) and the image fills it with `object-fit: contain`. Measured after the fix at 1440: every mark fits 176 × 56; widths 96–176, heights 22–56. At 390: box 128 × 40, widths 69–128.
