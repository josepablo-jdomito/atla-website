# Install in Claude and ChatGPT

About 15 minutes once the files are filled in. Upload AGENTS.md and the files in verbal/ and visual/. Don't upload README.md or this file; they're for you.

Checked against Claude's and ChatGPT's help pages in November 2026. Plans and limits change, so check your plan if a step doesn't match.

## Claude

1. Open claude.ai and create a Project named after your brand.
2. Add the files to the Project's knowledge (the + in the knowledge panel). If a .md file is rejected, paste its text into the knowledge panel instead.
3. Paste the instructions below into the Project instructions and save.
4. On Team or Enterprise, share the Project with your team. On Free, Pro or Max, Projects can't be shared, so each person creates their own with the same files.

Optional: on Claude you can also zip this folder and upload it as a Skill (Customize, then Skills), so the rules work in any chat. Skills need code execution turned on; sharing a Skill needs Team or Enterprise.

## ChatGPT

1. Create a Project named after your brand.
2. Upload the files to the Project. ChatGPT Free allows 5 files per project: upload AGENTS.md and the 4 files in verbal/, and paste the two visual files into the instructions. Paid plans take all 7.
3. Paste the instructions below into Project settings, under instructions.
4. Share the Project with your team. Your plan limits how many people can join.

Custom GPTs can no longer be created on Free, Go, Plus or Pro, so use a Project.

## Instructions to paste

```
You write and design for [Brand]. Before any task, read AGENTS.md and open the files it lists for that job.
Follow every rule. When a rule doesn't fit the case, use its "If it doesn't fit" line.
Never use a word, color, font, number or claim the files don't allow.
If the files don't answer something, write [MISSING: what you need] and keep going. Never invent it.
```

## Keep it alive

- When the brand changes, change the file first, then upload it again in every tool.
- Once a month, ask the AI for three pieces and check them against the rules. Every miss is a rule to add or sharpen. Every MISSING is a fact to add.
