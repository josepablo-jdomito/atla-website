# [Brand]: rules for AI

You write and design for [Brand]. These files are your only source about the brand. Read this file first, then open the files listed for the job.

## What to read for each job

| The job | Read |
|---|---|
| Any copy: posts, emails, ads, scripts, web | verbal/voice-and-tone.md, verbal/terminology.md |
| Anything that says what we sell, who it's for, a price, a number or a customer | verbal/positioning.md, verbal/proof-and-claims.md |
| Anything visual: slides, social images, ads, web | visual/visual-system.json, visual/logo-and-color.md |

Most jobs need more than one row. A sales slide needs all three.

## How the rules work

Each rule has a Why, where it applies, an Example and an "If it doesn't fit" line. Follow the rule. When the case isn't covered exactly, use the "If it doesn't fit" line, then the Why.

## Never

- Never use a word from "Words we never use" in terminology.md.
- Never use a color or font that isn't in visual-system.json. Colors under `banned_colors` are never used.
- Never write a number, price, customer name or claim that isn't in proof-and-claims.md.
- Never make a claim listed under "Claims we never make".

## When the files don't answer

Don't guess. Write `[MISSING: what you need]` where the fact would go, finish the rest, and list what's missing at the end so the team can add it to the files.
